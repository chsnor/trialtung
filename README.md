# TungTung EA (Trial Edition - 2 Months)

ระบบช่วยเทรดอัตโนมัติบน MetaTrader 5 (MT5) ขับเคลื่อนด้วย Machine Learning (ONNX) สไนเปอร์นัดเดียวคม สำหรับพอร์ตส่วนตัวทุน $300 (Leverage 1:500 - 1:2000)

> **ระยะเวลาทดลองใช้งาน:** 2 เดือนเต็ม (ใช้งานได้ถึงวันที่ 06/11/2026 23:59:59)

---

## การทำงานของ 2 โหมดในเวอร์ชันนี้

### 1. Personal Gold All-In Sniper (`01_Personal_Gold_AllInSniper_300.set`)
* **สินทรัพย์:** XAUUSD (ทองคำ) | ไทม์เฟรม: H1
* **เป้าหมาย:** ปั้นพอร์ตทุน $300 เร่งโต 3 เท่า (+200% ถึง +300%)
* **สเปก:** เสี่ยง 30% ทบต้น, Stop Loss 1.0x ATR, Take Profit Runner 3.5x ATR
* **การล็อกกำไร:** ตัดปิดล็อกกำไร 50% ของล็อตทันทีที่ราคาบวกถึง +1.5x ATR และตั้งกันทุน (Break-Even) ที่ +0.5x ATR ปล่อยอีก 50% รันเทรนด์ใหญ่
* **สถิติ:** วินเรตทดสอบ 88.6%

### 2. Personal Nasdaq All-In Sniper (`02_Personal_Nasdaq_AllInSniper_300.set`)
* **สินทรัพย์:** NAS100 / USTEC (แนสแด็ก) | ไทม์เฟรม: H1
* **เป้าหมาย:** สไนเปอร์เกาะเทรนด์ดัชนีหุ้นสหรัฐฯ พอร์ตทุน $300
* **สเปก:** เสี่ยง 30% ทบต้น, Stop Loss 1.0x ATR, Take Profit Runner 3.5x ATR
* **การล็อกกำไร:** ตัดปิดล็อกกำไร 50% ที่ +1.5x ATR และตั้งกันทุนที่ +0.5x ATR
* **สถิติ:** วินเรตทดสอบ 84.6%

## ขั้นตอนการติดตั้งใช้งาน

1. นำไฟล์ `TungTungEA.ex5` จากโฟลเดอร์ `Experts/` ไปวางที่ `MT5 -> MQL5 -> Experts`
2. นำไฟล์ `.set` ทั้งหมดในโฟลเดอร์ `Presets/` ไปวางที่ `MT5 -> MQL5 -> Profiles -> Presets`
3. เปิดกราฟ **XAUUSD (H1)** หรือ **NAS100 / USTEC (H1)**
4. ลาก `TungTungEA` ลงบนกราฟ ติ๊กถูกที่ **Allow Algo Trading (อนุญาตการเทรดอัตโนมัติ)**
5. ในแท็บ **Inputs** กดปุ่ม **Load** แล้วเลือกไฟล์ Preset ให้ตรงกับคู่เงิน
